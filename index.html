联机对战
先选角色：主机负责开局，客机负责应答
⚠ 当前是浏览器版。
能做的：「连接码」手动配对 —— 走 WebRTC 直连，不需要任何服务器； 「直连」也能进别人的房间（把对方开房后显示的地址填进去，对方用桌面版开房）。
做不了的：「局域网自动搜房」和「跨网 EasyTier」， 以及自己开房。网页不能监听端口、不能收 UDP 广播、也没有 mDNS 浏览 API —— 「被别人搜到」这半边浏览器永远做不到；跨网还得能拉起 EasyTier 进程。
注意：页面如果是 https:// 打开的（比如在线版），浏览器会把 http://192.168.x.x 的请求当混合内容拦掉，「直连」进房会失败 （127.0.0.1 除外，那算可信来源）。https 下能用的就是「连接码」； 想要直连 / 搜房请用桌面版，或者用 file://、本地 http 打开页面。
最多 6 人同局。主机接上一个人之后，按钮会变成「再让一个人进来」， 可以一个个加；玩家席满了以后发出去的码就是观战码（只能看，不能操作）。
同一个 Wi-Fi 下可以直接互相搜到
房主开好房间后会把地址显示出来，粘到这里就能搜到他的房间
两边填一样的网络名和密码，就能进同一张虚拟局域网； 起来之后下面会出现「搜索房间」，和同一个 Wi-Fi 时用法完全一样。

            玩法：开局先选「单人」或「本地双人」（按 1 / 2 也行）；
            联机对战走 WebRTC 直连：主机点「我是主机」生成连接码发给对方，
            对方点「我是客机」粘贴后生成应答码发回来，主机填进去即可开局（零服务器）；
            一条连接一个座位，主机可以一位一位地加，最多 6 人同局；玩家席坐满后
            再发出去的码就是观战码 —— 观战的人能看到整局画面，但不发任何操作；
            双人分「合作」和「竞争」：合作时队友出局后场上会出现粉色十字（✚），
            活着的人吃到就能把队友救回来；竞争时不能复活，炮塔会连对方一起打，先出局的一方输。
            双人同屏时 —— 🟢 P1 用方向键、🟠 P2 用 WASD，各自吃红色苹果（🍎）得分；
            吃到蓝色闪电（⚡）可在 30 秒内让步长减半，吃到金色箭头（⤢）可让场地上下左右各拓宽一格；
            紫色是敌人蛇，它也会抢苹果和闪电，撞到它即结束；
            红蛇生来就长（6 节），蓝蛇会朝你发射子弹（打中扣掉对应部位的血）；
            它阵亡后身体会原地掉成一地战利品：绿色 + 加身长，金币 + 加货币；
            P1 按 / 、P2 按 Q（或点各自的「建塔」）消耗 2 节身长 + 1 货币，可原地造一座自动开火的炮塔；
            两位玩家的得分 / 货币 / 炮塔各自独立，撞到对方身体同样会出局，一位出局另一位继续玩；
            按 P（或点「暂停」）可随时暂停，暂停期间所有计时都会一起停住。
